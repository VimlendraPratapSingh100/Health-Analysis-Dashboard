🏥 Smoking Health Risk Analysis Dashboard

📊 Project Overview

This project is an interactive Health Risk Analysis Dashboard
developed using Microsoft Power BI.

The dashboard analyzes the relationship between smoking habits,
age, BMI, cholesterol, hypertension, and different health conditions.

🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- CSV / Excel
- Data Visualization

📌 Dashboard Features

❤️ Health Condition Analysis
The dashboard provides analysis for different organs/health conditions
such as:

- Heart
- Kidney
- Liver
- Lungs

🚬 Smoking Analysis

- Smoking Status
- Never Smoker
- Current Smoker
- Former Smoker
- Smoking Duration & Daily Intake

📈 Health Risk Analysis

- Cholesterol Risk
- Hypertension Risk
- BMI Analysis
- Age Group Analysis
- Gender-wise Patient Analysis

📊 Key Visualizations

- KPI Cards
- Donut Chart
- Line Chart
- Bar Chart
- Interactive Slicers
- Health Condition Filters

🎯 Objective

The main objective of this project is to analyze smoking-related
health risks and identify patterns between smoking behavior and
different health indicators.

💡 Key Insights

The dashboard helps identify patterns related to:

- Smoking status
- Age groups
- BMI
- Cholesterol
- Hypertension
- Smoking duration
- Daily smoking intake
- Gender distribution
